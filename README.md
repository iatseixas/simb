# SIMB — protótipo funcional

Abra `index.html` diretamente no navegador. Use a matrícula `100001` e a senha `simb123`.

Os dados são fictícios e ficam salvos no `localStorage` do navegador. O botão circular no canto superior direito restaura o conjunto inicial.

Para instalar como PWA e habilitar o modo offline, sirva esta pasta em `localhost` (por exemplo, com `python -m http.server 8080`) e abra `http://localhost:8080`.
